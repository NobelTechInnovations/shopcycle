1. Business overview

Oyklane lets small and medium businesses build an online store, sell products, take payments, and ship orders. Merchants pay Oyklane a monthly subscription. Many of them have never advertised online, and Google Ads is too complex for them to set up alone.

The Oyklane Google Ads Manager lets a merchant run Google Ads campaigns for their own store from the dashboard they already use. Every merchant uses their own Google Ads account, billed by Google to their own payment method. Oyklane does not buy media, resell ads, mark up spend, or handle ad payments. The tool is free for merchants.

2. How merchants connect

  1. The merchant opens Apps ▸ Google Ads and signs in with Google (OAuth 2.0, scope https://www.googleapis.com/auth/adwords). Access can be removed at any time from the dashboard or from their Google account.
  2. Oyklane lists the Google Ads accounts that login can reach (CustomerService.ListAccessibleCustomers, plus client accounts of any manager account they own), and the merchant picks the one for their store.
  3. No Google Ads account yet: the merchant can create one from Oyklane. Oyklane's manager (MCC) account creates a client account (CustomerService.CreateCustomerClient) in the store's currency and time zone, and invites the merchant's email as its Admin. The merchant accepts Google's invitation and adds their own billing in Google Ads.
  4. Oyklane checks the account: purchase conversion tracking, linked Merchant Center, currency and time zone. It then offers one-click setup of a "Purchase" conversion action, whose tag Oyklane places on the store's order-confirmation page.

4. Users and access

  • External users (merchants). Each merchant reaches only the Google Ads account(s) their own Google login can access, for their own store. Merchants never see other merchants' data.
  • Internal users (Oyklane staff). Platform setup (Google Cloud project, manager account) and support. Staff do not run campaigns on merchants' behalf.
  • Store roles. Within a store, only the owner or an admin can create, change or remove campaigns. Staff accounts can only view reports.

5. Technical design

  • Architecture. Next.js merchant dashboard → Oyklane API (Node.js) → Google Ads API REST (current supported version). All Google Ads calls are made server-side; OAuth tokens never reach the browser. API access is set on the Google Cloud project of Oyklane's OAuth client (no developer token since September 2026).
  • Authentication. OAuth 2.0 web flow per merchant. Refresh tokens are stored encrypted (AES-256-GCM) and are deleted when the merchant disconnects. The login-customer-id header is used when an account is reached through a manager account.
  • Mutations. Campaign creation is a single atomic googleAds:mutate request, so a campaign is either fully created or not created. Each change is recorded in the store's activity log (who, what, when, before and after).
  • Errors. Google Ads failures are translated into plain language for the merchant, for example "This account isn't active yet — finish billing in Google Ads".
  • Rate limits and volume. Reports are cached for several minutes and refreshed on request. Expected volume at launch is under 100 linked accounts and under 10,000 operations a day, growing with the merchant base and well inside Basic access limits.
  • Data use. Google Ads data is used only to show the merchant their own results and to make suggestions to them. It is not sold, shared with third parties, or combined across merchants.

7. Google Ads API services used

CustomerService (ListAccessibleCustomers, CreateCustomerClient) · GoogleAdsService (Search, Mutate) · CampaignBudgetService, CampaignService, CampaignCriterionService, AdGroupService, AdGroupCriterionService, AdGroupAdService, AssetService, AssetGroupService, AssetGroupAssetService, ConversionActionService (all through GoogleAdsService.Mutate) · KeywordPlanIdeaService (GenerateKeywordIdeas) · GeoTargetConstantService (SuggestGeoTargetConstants) · RecommendationService (ApplyRecommendation, DismissRecommendation).

Oyklane does not use the App Conversion Tracking and Remarketing API. This application is for the Google Ads API only.
